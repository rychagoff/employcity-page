# Руководство по внесению изменений

#### 1. Своя ветка для каждого блока. Ветка разработки - `develop`

Сперва создаём из `main` ветку `develop`, затем для каждого блока/секции страницы свою ветку.

#### 2. После завершения блока/секции нужно залить изменения в `develop`, затем слить с `main`
